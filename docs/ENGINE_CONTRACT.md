# Implementation contract

The browser UI, worker, Node CLI and optional loopback HTTP companion share one engine. Vite bundles the website; GitHub Actions hosts static `dist` through Pages. FFmpeg single-thread wasm is self-hosted in `codecs/` (copied at build). Core engine imports pure DSP/SoundTouch; it does not require the DOM or ffmpeg.wasm.

## Audio and project model

`AudioData = { sampleRate: number, channels: Float32Array[] }`. One or two channels initially. All channels equal length and finite. Audio may exceed +/-1 inside float processing; no silent input clipping. A project has `version: 1, name, sampleRate: 48000, bpm: 120, beatsPerBar: 4, beatOffset: 0, tracks: [], selection: null, settings: {}`. Each track: `{ id, name, gainDb: 0, pan: 0, mute: false, solo: false, clips: [] }`. Each clip: `{ id, name, start: 0, audio }`; start is seconds on the timeline. Selection `{trackId, clipId, start, end, channels:'all'|'left'|'right'}` is in seconds RELATIVE TO THE CLIP. Selection is null or one nonempty interval. Effects default to selection if present, else selected clip; API explicit target overrides. Time/length-changing operations restricted to all channels for coherence. Duration edits affect one clip; no hidden project ripple unless requested. IDs generated by engine.

## DSP module (src/dsp.js)

`processAudio(audio, effect, params={}, context={bpm,beatOffset,sidechain}) -> Promise<AudioData>`;
`detectBpm(audio,{minBpm,maxBpm}={}) -> {bpm,confidence,candidates,beatOffset}`;
`detectSilence(audio,{thresholdDb,minDuration,padding}={}) -> [{start,end}]`;
`analyzeAudio(audio) -> {peakDb,rmsDb,duration,channels,sampleRate,clippedSamples,dcOffset,correlation}`;
`generateAudio({type:'tone'|'noise'|'sweep'|'drums',sampleRate,duration,frequency,endFrequency,amplitude,seed,bpm}) -> AudioData`;
`sliceAudio(audio,start,end)`, `concatAudio(parts)`, `resampleAudio(audio,sampleRate)`.

Effects: gain (db); fadeIn/fadeOut (duration); normalize (targetDb); reverse; invert; phase (delayMs); pan (pan -1..1); mono; swap; eq (bands:[{type:'peaking'|'lowpass'|'highpass'|'lowshelf'|'highshelf',frequency,gainDb,q,enabled}]); compressor (thresholdDb,ratio,attackMs,releaseMs,kneeDb,makeupDb); limiter (ceilingDb,releaseMs,lookaheadMs); stretch (ratio=outputDuration/inputDuration, preservePitch=true); pitch (semitones,preserveDuration=true); speed (rate); silence; removeSilence (thresholdDb,minDuration,padding); dcRemove; duck (mode:'volume'|'compressor',source:'tempo'|'track',depth,rate=beats per cycle,attack,hold,release,curve,points:[{x,y}],thresholdDb,ratio,attackMs,releaseMs; context.sidechain actual trigger audio); loop (repeats,crossfadeMs); beatRepeat (division,pattern:[indexes],bpm); granular (grainMs,density,spread,seed,mix).

Pure `src/wav.js`: `encodeWav(audio,{bitDepth:16|24|32,float=false}={}) -> Uint8Array`; `decodeWav(Uint8Array|ArrayBuffer) -> AudioData`.

## Engine module (src/engine.js)

`export class AudioEditor` with `constructor({sampleRate=48000}={})`, `async execute(method,params={})`, `getState()` metadata WITHOUT raw PCM; `getProject()` live project (internal); command registry `COMMANDS` with method, description, parameter hints. `execute` uniform async for browser/Node. Engine imports DSP, exposes all functionality through command registry. Every destructive edit undoable and resets redo. History bounded by count and memory, validation/rollback for invalid commands, no external eval. JSON import version/resource validation; portable projects embed PCM base64. `project.save` returns JSON object; `project.load` accepts `{project}`. `settings.save/load`, `history.undo/redo`, `project.new/update`, `track.add/update/remove`, `clip.add/update/remove/duplicate/split`, `selection.set/clear`, `edit.cut/copy/paste/delete/trim`, `effect.apply/preview`, `analysis.bpm/silence/stats`, `audio.generate`, `audio.render`, `markers.add/remove`, `loop.create`, `recipe.run`. `clip.add` receives `{trackId?,name?,start?,audio}`. `effect.apply` receives `{effect,params,target?:{trackId,clipId,start,end,channels}}`. `effect.preview` same parameters, returns WHOLE target clip AudioData with selected region replaced without commit. `audio.render` receives `{scope:'mix'|'track'|'clip'|'selection',trackId?,clipId?,start?,end?}` returns AudioData. `clip.getAudio` receives clipId. `analysis.*` uses selected range, or explicit target. `audio.generate` creates a new track+clip unless supplied trackId. State includes selectedTrackId,selectedClipId; add/selection commands update them. `selection.set` clips range and validates against selected clip. `project.select` accepts trackId,clipId without edit. UI uses same command dispatch. UI transport/view/file operations use their own registered adapter and are documented as UI-only.

## Worker

Parent implements worker adapter around AudioEditor.execute. Responses `{id,result,state}`; errors `{id,error:{message,code}}`; typed arrays structured cloned. Serialized job execution; previews replace stale requests in UI. All edit render work in worker. `window.websoundedit` public facade with execute(), commands(), getState(), importFile(), exportAudio(), saveProject(), loadProject(), transport methods.

## Companion

Node CLI `node scripts/cli.mjs --input in.wav --recipe recipe.json --output out.wav`, optional native ffmpeg for other codecs. Loopback HTTP JSON API with printed random bearer token, Host/origin checks, size cap, no arbitrary file path read from requests; raw audio data endpoints import/export and JSON commands. Binding is 127.0.0.1; authenticated scripts can send bytes. Every core editing operation available, batch through recipe. Browser transport remains browser-only. Scripts can also import AudioEditor directly.
