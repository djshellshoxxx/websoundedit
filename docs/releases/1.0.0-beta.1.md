# WebSoundEdit 1.0 beta

[Open the editor](https://djshellshoxxx.github.io/websoundedit/) · [Source and reproducible checks](https://github.com/djshellshoxxx/websoundedit/tree/v1.0.0-beta.1) · [Specification](https://github.com/djshellshoxxx/websoundedit/blob/v1.0.0-beta.1/docs/specs/BETA_1_0.md)

This beta extends the published creative workbench into an audio editor, macro processor and live looping workspace. Audio processing stays on the device. Browser features request their own permissions when used.

## Editing and sound

- Twelve ordered effects: echo, delay, reverb, chorus, flanger, phaser, distortion, tremolo, filter, tape, stutter and bitcrusher. Drag to reorder or use keyboard controls; each stage has its own wet/dry value.
- Destructive selection processing and an independent live effects rack. The XY pad maps two chosen parameters; audio-clock automation schedules parameter changes during transport.
- Colorful multichannel waveforms, sample-key estimates with confidence and manual overrides, selection zoom, a collapsible sound-tools panel, and individual track close/save/export actions.
- Mono, stereo, 5.1 and 7.1 PCM, WAV and explicit conversion matrices. Physical monitoring depends on the selected device and browser. Pitch-preserving WSOLA currently supports mono/stereo; linked speed changes support all four layouts.
- Metadata editing and format-specific export reporting, theme selection, MIDI note/CC mappings, MIDI pedal actions and MIDI file exchange.

## Automation and live performance

- Macro1 scripts with variables, expressions, if/else, repeat/for/while, waits, cancellation and bounded resource use. Record successful user actions into canonical text, edit visually or as text, assign shortcuts and run isolated sequential batches.
- One typed command catalog backs browser controls, the SDK, macro interpreter and companion API. Browser-only methods are explicitly unavailable in a headless runtime.
- Microphone/instrument and available system-audio capture, independent loop layers, button or MIDI pedal triggering, per-loop play/stop/mute/delete and program capture.
- Disk-backed long recording through an OPFS worker, bounded queues, recovery manifests, range audition/import and streamed WAV/RF64 export. A long archive remains separate from the resident waveform editor's 10-minute/256 MiB limits.
- Opt-in UDP streaming through an authenticated local Node companion. Only operator-configured destinations and supported profiles are selectable. Profiles include raw s16le/f32le, Opus/Ogg, MP3, AAC/MPEG-TS and FLAC; compressed profiles and resampling require native FFmpeg.

## Projects and guidance

- Editable WebSoundEdit sessions, per-track sessions, mixed exports and stems.
- Real Audacity AUP3 and legacy AUP exchange; surround export explicitly splits into speaker-labeled mono tracks.
- Real REAPER RPP plus referenced WAV media in ZIP, with a bounded importer for supported audio tracks, trims, timing, markers, constant mix and fixed tempo. Active third-party plugins and unsupported DAW constructs are rejected or explained rather than silently changed.
- Addressable Options, global tooltip control, searchable help and annotated screenshots of the actual interface.

## Verification

Publication requires unit/integration tests, seeded audio/PCM/parser/API/macro fuzz corpora, dependency auditing, production SDK validation, native Audacity and pinned REAPER 7.86 verification, and Chromium UI/worklet/capture tests. The main workflow verifies the deployed page, illustrated Help and GitHub wiki before creating this prerelease. Source reports and audit findings are in `docs/audits/`; exact-run artifacts are attached to the corresponding GitHub Actions run.

Tests use synthetic media and bounded recording sequences. They do not establish uninterrupted multi-hour recording on every machine, physical MIDI pedal compatibility, hardware surround routing, or full fidelity for arbitrary Audacity/REAPER plugins. Key detection is an estimate. UDP can lose packets; queue and loss counters are exposed.
